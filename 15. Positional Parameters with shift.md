# 15. Positional Parameters with shift

## Positional Parameters Recap

| Parameter | Meaning |
|---|---|
| `$0` | Program or script name |
| `$1` … `$9` | Parameters passed |
| `$#` | Total number of parameters |
| `$*` | All parameters passed |
| `$@` | Same as `$*` |
| `$$` | PID of the current shell |

```bash
#!/bin/bash
echo "This is positional parameter example script" $0
echo "Hello, My name is : " $1
echo "Here is " $2
echo "this is " $3
echo "total count value is " $#
echo "Display the parameter the passed" $*
echo "Fetch information" $@
echo "PID of current shell"
echo "Exit status of last executed command " $?
```


```bash
#!/bin/bash
echo "count $#"
echo "$1 $2 $3"
shift
echo "$1 $2 $3"
echo "count $#"
```

```console
# ./shift.sh Ahmad Hassan Ali
count 3
Ahmad Hassan Ali
Hassan Ali
count 2
```

## Multi-Position Shift

```bash
#!/bin/bash
echo "count $#"
echo "$1 $2 $3 $4 $5"
shift 2
echo "$1 $2 $3 $4 $5"
echo "count $#"
```

```console
# ./shift.sh Ahmad Hassan Ali Sara Kazim
count 5
Ahmad Hassan Ali Sara Kazim
Ali Sara Kazim
count 3
```

## Difference Between `$@` and `$*`

```bash
#!/bin/bash

echo -e "Example of : \$*\n"
for each in $*
do
echo $each
done

echo -e "Example : \$@\n"
for each in "$@"
do
echo $each
done
```

