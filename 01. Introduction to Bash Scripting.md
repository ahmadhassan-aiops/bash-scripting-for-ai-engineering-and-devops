# 01. Introduction to Bash Scripting

## Decimal to Binary

Bit place values:

```
128 64 32 16 8 4 2 1
```

| Decimal | Binary |
|---|---|
| 12 | `00001100` |
| 15 | `00001111` |
| 68 | `01000100` |
| 8 | `00001000` |
| 97 | `01100001` |

## Checking Your Shell

```bash
echo $SHELL
env

```

## Your First Script

```bash
mkdir /opt/bash
vim test
```

Write the following inside `test`:

```bash
echo "hello"
```

Run it with either shell. Both print `hello`:

```bash
bash test
sh test
```

Running it directly gives a **permission denied** message:

```bash
./test
```

Give the file execute permission, then run it again. Now `hello` is printed:

```bash
chmod +x test
./test
```
