# 11. while Loop and IFS

**Infinite loop:** when the condition has no limit, the loop runs forever.

## Syntax

```bash
while condition
do
 statement
done
```

## Infinite Loop

```bash
vim infinity.sh
```

```bash
#!/bin/bash
while true
do
 echo "CloudOps"
 echo "********"
done
```

## Counting Up

```bash
#!/bin/bash
start=1
while [[ $start -le 10 ]]
do
 echo "CloudOps : $start"
 ((start++))
done
```

## Counting Down

```bash
#!/bin/bash
start=10
while [[ $start -ge 1 ]]
do
 echo "CloudOps : $start"
 ((start--))
done
```

## Reading File Contents

**Syntax:**

```bash
while read line
do
 statement
done < filename
```

```bash
vim name.txt
```

```
1,Ahmad
2,Kazim
3,Ali
```

```bash
vim fileread.sh
```

```bash
#!/bin/bash
file="name.txt"
while read each_line
do
 echo "$each_line"
done < $file
```

**Syntax with a command:**

```bash
command | while read <variable>
do
 statement
done
```

```bash
#!/bin/bash
file="/root/bash/lect11/name.txt"
cat $file | while read each_line
do
echo "$each_line"
done
```

## while Loop with IFS

**IFS** = Internal Field Separator

Example CSV line: `1,Ahmad,12,34`

**Syntax:**

```bash
while IFS="Separator" read variable1 variable2 variable3
do
 statement
done < filename
```

or

```bash
command | while IFS="Separator" read variable1 variable2 variable3
do
 statement
done
```

```bash
vim server.csv
```

```
1,Ansible,192.168.1.8
2,Node1,192.168.1.9
3,Node2,192.168.1.10
4,Node3,192.168.1.11
```

**Print only the IPs of the servers:**

```bash
#!/bin/bash
file="/root/bash/lect11/server.csv"
cat $file | while IFS="," read var1 var2 var3
do
echo "$var3"
done
```

**Space-separated file:**

```bash
#!/bin/bash
file="/root/bash/lect11/server1.csv"
while IFS=" " read var1 var2 var3
do
echo "$var2"
done < $file
```

The default separator is a space, so for a space-separated file you can leave out `IFS`:

```bash
#!/bin/bash
file="/root/bash/lect11/server1.csv"
while read var1 var2 var3
do
echo "$var2"
done < $file
```
