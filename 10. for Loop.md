# 10. for Loop

## Syntax

```bash
for variable in list
do
echo "Statement"
done
```

## Simple Example

```bash
#!/bin/bash
for var in 1 2 3 4 5
do
echo Hello-$var
done
```

**Output:**

```console
./simple.sh
Hello-1
Hello-2
Hello-3
Hello-4
Hello-5
```

## Interview Question

**How do you create 10 files with a single command?**

```bash
touch file{1..10}
```

## Range with a Step

```bash
vim simple.sh
```

```bash
#!/bin/bash
for i in {1..11..2}
do
echo "Welcome $i"
done
```

**Output:**

```console
./simple.sh
Welcome 1
Welcome 3
Welcome 5
Welcome 7
Welcome 9
Welcome 11
```

## C-Style Syntax

The C programming style also works:

```bash
for ((var=1; var<=5; var++))
do
echo $var
done
```

## Checking Execute Permission

**Single file:**

```bash
#!/bin/bash
if [[ -x file9 ]]
then
echo "simple.sh is having execution permission"
else
echo "simple.sh is is not having exe permission"
fi
```

**Several files:**

```bash
#!/bin/bash
for each in file1 file2 file3 file4 file5
do
if [[ -x $each ]]
then
echo "$each is having execution permission"
else
echo "$each is is not having exe permission"
fi
done
```

## File or Directory?

```bash
#!/bin/bash
for each in $(ls)
do
if [[ -f $each ]]
then
echo "$each is file"
else
echo "$each is directory"
fi
done
```
