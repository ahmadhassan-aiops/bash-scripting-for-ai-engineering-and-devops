# 20. grep Filter

`grep` is used to filter content.

## Syntax

```bash
file or message | grep <option>
# or
grep <option> file or message
```

```console
# cat ahmad.txt
My name is Ahmad Hassan
I am from Rawalpindi , Pakistan
I am working in CloudOps as Devops trainer

# cat ahmad.txt | grep "Devops"
I am working in CloudOps as Devops trainer

# grep "Devops" ahmad.txt
I am working in CloudOps as Devops trainer
```

## `-i`, `--ignore-case`

Ignore case distinctions in patterns and input data, so characters that differ only in case match each other.

```console
root@ahmadhassan:~/bash/lect21# cat ahmad1.txt
Ahmad here, We are learning bash script
root@ahmadhassan:~/bash/lect21# cat ahmad1.txt | grep "ahmad"
root@ahmadhassan:~/bash/lect21# cat ahmad1.txt | grep -i "ahmad"
Ahmad here, We are learning bash script
```

```bash
cat /var/log/syslog | grep -i "error "
cat /var/log/syslog | grep -i "error" > error.txt
cat /proc/cpuinfo | grep -i "model"
```

## `-w`, `--word-regexp`

Select only lines whose matches form whole words. The match must be at the beginning of the line or preceded by a non-word character, and at the end of the line or followed by a non-word character.

```console
# cat ahmad.txt
My name is Ahmad Hassan
I am from Rawalpindi , Pakistan
I am working in CloudOps as Devopsss trainer
We are learning bash script , devopssss
devops
Devopsss


We will learn some automation tools in devops course.
We will cover real time example which you are using day by day in your job.
Devops course very important for all

# cat ahmad.txt | grep "Devops"
I am working in CloudOps as Devopsss trainer
Devopsss
Devops course very important for all

# cat ahmad.txt | grep -w "Devops"
Devops course very important for all
```

## `-v`, `--invert-match`

Invert the match to select non-matching lines.

```bash
cat ahmad.txt | grep -v "Devops"

cat /etc/apache2/sites-available/default-ssl.conf | grep -v "#"
cat /etc/apache2/sites-available/default-ssl.conf | grep -v "#" > out.txt
```

## `-o`, `--only-matching`

Print only the matched parts of each line, each on its own line.

```console
root@ahmadhassan:~/bash/lect21# cat ahmad.txt | grep -o "Devops"
Devops
Devops
Devops
root@ahmadhassan:~/bash/lect21# cat ahmad.txt | grep -io "Devops"
Devops
devops
devops
Devops
devops
Devops
```

## `-c`, Count Matching Lines

```console
# cat ahmad.txt | grep -c "Devops"
3
# ps -ef | grep -c $USER
157
```

## Context: `-A`, `-B`, `-C`

| Option | Prints |
|---|---|
| `-A NUM`, `--after-context=NUM` | NUM lines after each match |
| `-B NUM`, `--before-context=NUM` | NUM lines before each match |
| `-C NUM`, `--context=NUM` | NUM lines before and after each match |

A `--` separator is placed between groups of matches. These options have no effect with `-o`.

```console
# cat ahmad.txt | grep -A 1 "CloudOps"
I am working in CloudOps as Devopsss trainer
We are learning bash script , devopssss

# cat ahmad.txt | grep -B 1 "CloudOps"
I am from Rawalpindi , Pakistan
I am working in CloudOps as Devopsss trainer

# cat ahmad.txt | grep -C 1 "CloudOps"
I am from Rawalpindi , Pakistan
I am working in CloudOps as Devopsss trainer
We are learning bash script , devopssss
```

## `-r`, `--recursive`

Read all files under each directory, recursively. If no file is given, grep searches the working directory.

```console
root@ahmadhassan:~/bash/lect21# grep -r "Devops"
ahmad.txt:I am working in CloudOps as Devopsss trainer
ahmad.txt:Devopsss
ahmad.txt:Devops course very important for all
test/ahmad.txt:I am working in CloudOps as Devopsss trainer
test/ahmad.txt:Devopsss
test/ahmad.txt:Devops course very important for all
```

## `-l`, `--files-with-matches`

Print only the names of files that contain a match. Scanning stops at the first match.

```console
root@ahmadhassan:~/bash/lect21# grep -l "Devops" *
ahmad.txt
grep: test: Is a directory
root@ahmadhassan:~/bash/lect21# grep -l "Devops" ahmad.txt
ahmad.txt
root@ahmadhassan:~/bash/lect21# grep -l "Devops" ahmad1.txt
```

## `-h`, `--no-filename`

Suppress the file-name prefix on output (the default when searching only one file).

```console
# grep -h "Devops" *
I am working in CloudOps as Devopsss trainer
Devopsss
Devops course very important for all
```

## Multiple Patterns: `-e`, `-E` and `egrep`

```console
# cat ahmad.txt | grep -e "Devops" -e "trainer" -e "learning"
I am working in CloudOps as Devopsss trainer
We are learning bash script , devopssss
Devopsss
Devops course very important for all

# cat ahmad.txt | grep -E "Devops|learning"
I am working in CloudOps as Devopsss trainer
We are learning bash script , devopssss
Devopsss
Devops course very important for all

root@ahmadhassan:~/bash/lect21# cat ahmad.txt | egrep "Devops|learning"
I am working in CloudOps as Devopsss trainer
We are learning bash script , devopssss
Devopsss
Devops course very important for all

# cat /etc/passwd | grep -Ew "root|cloudops"
root:x:0:0:root:/root:/bin/bash
cloudops:x:1006:1008::/home/cloudops:/bin/bash
```

## `-f FILE`, Patterns from a File

Read patterns from FILE, one per line. An empty file contains no patterns and matches nothing.

```console
# cat user.txt
root
ahmad
aadmin
cloudops

# cat /etc/passwd | grep -wf user.txt
root:x:0:0:root:/root:/bin/bash
ahmad:x:1000:1000:Ahmad,,,:/home/ahmad:/bin/bash
aadmin:x:1001:1001::/home/aadmin/:/bin/bash
cloudops:x:1006:1008::/home/cloudops:/bin/bash
```

## Regular Expressions

**`^` matches at the beginning of a line:**

```console
# cat ahmad.txt | grep -E "Devops"
I am working in CloudOps as Devopsss trainer
Devopsss
Devops course very important for all
root@ahmadhassan:~/bash/lect21# cat ahmad.txt | grep -E "^Devops"
Devopsss
Devops course very important for all
```

```bash
cat /etc/ssh/sshd_config | grep -v "^#"
```

Find only directories in the current location:

```console
# ls -ltrh | grep -E "^d"
drwxr-xr-x 2 root root 4.0K Jul  9 17:29 test
```

Find only files in the current location:

```console
# ls -ltrh | grep -E "^-"
-rw-r--r-- 1 root root   42 Jul  9 17:05 ahmad1.txt
-rw-r--r-- 1 root root  75K Jul  9 17:09 error.txt
-rw-r--r-- 1 root root  323 Jul  9 17:15 ahmad.txt
-rw-r--r-- 1 root root  538 Jul  9 17:19 out.txt
-rw-r--r-- 1 root root   27 Jul  9 17:39 user.txt
root@ahmadhassan:~/bash/lect21# ls -ltrh | grep -cE "^-"
5
```

**`$` matches at the end of a line:**

```console
# cat ahmad.txt | grep -E "all$"
Devops course very important for all
```

**`^$` matches empty lines:**

```console
root@ahmadhassan:~/bash/lect21# cat ahmad.txt | grep -E "^$"

root@ahmadhassan:~/bash/lect21# cat ahmad.txt | grep -vE "^$"
My name is Ahmad Hassan
I am from Rawalpindi , Pakistan
I am working in CloudOps as Devopsss trainer
We are learning bash script , devopssss
devops
Devopsss
We will learn some automation tools in devops course.
We will cover real time example which you are using day by day in your job.
Devops course very important for all
```

**`\` escapes special characters:**

```console
# cat ahmad.txt
My name is Ahmad Hassan
I am from Rawalpindi , Pakistan +
I am working in $  CloudOps as Devopsss trainer
We are learning bash script , devopssss
devops
Devopsss


We will learn some automation +  tools # in devops course.
We will cover real time example which you are using day by day in your job.
Devops course very important for all

# cat ahmad.txt | grep "\."
We will learn some automation +  tools # in devops course.
We will cover real time example which you are using day by day in your job.

# cat ahmad.txt | grep "\+"
I am from Rawalpindi , Pakistan +
We will learn some automation +  tools # in devops course.
```

**`.` matches any single character:**

```console
root@ahmadhassan:~/bash/lect21# cat ahmad.txt | grep -E "W."
We are learning bash script , devopssss
We will learn some automation +  tools # in devops course.
We will cover real time example which you are using day by day in your job.
```

```console
root@ahmadhassan:~/bash/lect21# cat ahmad.txt | grep -E "i."
My name is Ahmad Hassan
I am from Rawalpindi , Pakistan +
I am working in $  CloudOps as Devopsss trainer
We are learning bash script , devopssss
We will learn some automation +  tools # in devops course.
We will cover real time example which you are using day by day in your job.
Devops course very important for all
```

**`\b` matches a whole word:**

```console
# cat ahmad.txt | grep -E "\bDevops\b"
Devops course very important for all
```

**`?` and `*` quantifiers:**

```console
# cat > test.txt
india, innnnnn
iaaaaaaaaaaaaa
innnnnnnnnnnnnnnnnnnnnn
in
innnnnnnnnnnnnnnnnnn
i
innnnn

root@ahmadhassan:~/bash/lect21# cat test.txt | grep -E "in?"
india, innnnnn
iaaaaaaaaaaaaa
innnnnnnnnnnnnnnnnnnnnn
in
innnnnnnnnnnnnnnnnnn
i

# cat test.txt | grep -E "in*"
india, innnnnn
iaaaaaaaaaaaaa
innnnnnnnnnnnnnnnnnnnnn
in
innnnnnnnnnnnnnnnnnn
i
innnnn
```

**`{N}` matches exactly N times:**

```console
# cat test.txt | grep -E "in{5}"
india, innnnnn
innnnnnnnnnnnnnnnnnnnnn
innnnnnnnnnnnnnnnnnn
innnnn
root@ahmadhassan:~/bash/lect21# cat test.txt | grep -wE "in{5}"
innnnn

# cat test.txt | grep -wE "in{5,7}"
india, innnnnn
innnnn
```

## Matching IP Addresses

```console
# cat myip.txt
hello dear, my server details are as follow
My jboss server ip address is 192.168.1.8
My docker server ip address os 192.168.1.10
my brodcat address is 255.255.255.0
Invalid ip address 1234.1234.12.1
We are checking only for grep example

# cat myip.txt | grep -E "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}"
My jboss server ip address is 192.168.1.8
My docker server ip address os 192.168.1.10
my brodcat address is 255.255.255.0

# cat myip.txt | grep -E "\b[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\b"
My jboss server ip address is 192.168.1.8
My docker server ip address os 192.168.1.10
my brodcat address is 255.255.255.0
```
