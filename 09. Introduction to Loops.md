# 09. Introduction to Loops

## What Is a Loop?

In programming languages, a loop handles any task that is repeated more than once.

A loop is a sequence of instructions that is repeated continuously until a certain condition is reached.

## Types of Loops

1. `for` loop
2. `while` loop
3. `until` loop
4. `select` / `case`

## for Loop Syntax

```bash
for variable in list
do
echo "Statement"
done
```

## Why Loops? Smart Work

Doing it by hand, one file or user at a time:

```bash
touch file1
touch file2 file3 file4 file5
adduser user1 user2 user3
```

Creating files 1 to 100, or 50 users, this way is slow. A loop does it smartly.

```bash
ls -ltrh
ls /etc/resolved.conf
```

A loop can also read a file line by line and redirect the output:

```console
# cat ahmad.txt
Ahmad Hassan
from CloudOps Academy
Rawalpindi , Pakistan
```
