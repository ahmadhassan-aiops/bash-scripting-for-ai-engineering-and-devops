# 07. Nested if Conditions

| Keyword | Has `then` | Has `fi` |
|---|---|---|
| `if` | Yes | Yes |
| `else` | No | No |
| `elif` | Yes | No |

## Example: Largest of Three Numbers

```bash
#!/bin/bash
echo -n "Enter the first number:"
read var1
echo -n "Enter the second number:"
read var2
echo -n "Enter the third number"
read var3

if [[ $var1 -ge $var2 ]]
then
if [[ $var1 -ge $var3 ]]
then
echo "$var1 is largest number"
else
echo "$var3 is largest number"
fi
else
if [[ $var2 -ge $var3 ]]
then
echo "$var2 is largest number"
else
echo "$var3 is largest number"
fi
fi
```
