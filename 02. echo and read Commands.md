## The Shebang Line

```bash
vim myfirst
```

```bash
#!/bin/bash
docker -v
uname
```

A **shebang** is the character sequence `#!` written on the first line of a script file. It is also known as a hashbang or sha-bang.

## Variables

A variable can store any value.

```bash
ahmad=10
echo ahmad      # output: ahmad
echo $ahmad     # output: 10
```

To store the output of a Linux command, use the syntax `$(LINUX command)`.

```bash
a="ls"
echo $a         # output: only the text "ls"

a=$(ls)
echo $a         # output: the actual result of ls
```

A variable keeps the output from the moment it was set:

```bash
touch file2.txt file3 file4
echo $a         # the newly created files are NOT shown

a=$(ls)
echo $a         # now the new files are shown
```

## The read Command

Without a variable name, `read` stores the input in `$REPLY`:

```console
# read
Ahmad
# echo $REPLY
Ahmad
```

**Syntax:**

```bash
read <variable name>
```

```console
# read name
salman
# echo $name
salman
```

## Task

```bash
read -p "Enter your name:" name
read -p "Enter the name :" fname
read -p "Enter the name :" lname
echo $name
echo $fname
echo $lname
```

Read 5 characters, then exit:

```bash
read -n5 -p "Enter any key to exit :"
```

Use a command inside a string:

```bash
echo file.$(date).txt
```

## Summary

- `echo` is used for printing statements.
- `read` is used for storing input in variables.
