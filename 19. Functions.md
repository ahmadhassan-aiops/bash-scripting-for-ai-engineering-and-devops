# 19. Functions

A **function** is a block of code that removes repeated lines from your script and helps organise a long script into manageable modules.

## Two Ways to Define a Function

**Method 1:**

```bash
function <functionname>()
{
statement
}
```

**Method 2:**

```bash
<functionname>()
{
statement
}
```

## Calling a Function Several Times

```bash
#!/bin/bash
test()
{
echo "Ahmad Hassan"
echo "Hello Everyone"
}
echo " i am using sample function"
test

echo "This is my another function calling"
test

echo "===============Third times=========="
test
```

The same script using the `function` keyword:

```bash
#!/bin/bash
function test()
{
echo "Ahmad Hassan"
echo "Hello Everyone"
}
echo " i am using sample function"
test

echo "This is my another function calling"
test

echo "===============Third times=========="
test
```

## Variables in Functions

1. Global
2. Local

```bash
#!/bin/bash
mytest()
{
echo "my value is : $ahmad"
}

ahmad=12
mytest
```

**Global variables:**

```console
root@ahmadhassan:~/bash/lect20# cat global.sh
```

```bash
#!/bin/bash
mytest()
{
ali=12
echo "my value is : $ahmad"
ahmad=15
}

ahmad=13
mytest
echo "My second value is $ahmad"
```

**Local variables:**

```console

```

```bash
#!/bin/bash

mytest()
{
ali=12
echo "AHMAD value is $ahmad"
kazim=13
local cloudops=786
}

mytest
echo "Ali value is $ali"
echo "Kazim value is $kazim"
echo "CloudOps value is $cloudops"
```

**Capturing a function's output:**

```bash
#!/bin/bash

mytest()
{
local ali=10
echo "Ali value is $ali"
}
mytest
ali=$(mytest)

echo "Ali value is outside function : $ali"
```

## Return Values

```bash
vim return.sh
```

```bash
#!/bin/bash

myvar()
{
local ali=10
return $ali
}
myvar
echo "My return value is : $?"
ahmad=$?
echo "My return value is $ahmad"
```

## Passing Arguments

```bash

test()
{
echo "Hello $1"
}
```
