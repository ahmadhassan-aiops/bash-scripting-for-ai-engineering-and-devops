# 16. break and continue Statements

| Statement | Purpose |
|---|---|
| `break` | Terminates (exits) the current loop |
| `continue` | Skips the current iteration and continues with the next one |

## A Plain Loop

```console
root@ahmadhassan:~/bash/lect16# cat break_st.sh
```

```bash
#!/bin/bash

echo "Starting the loop"
for i in $(seq 1 10)
do
echo $i
done
echo "Ending the loop"
```

## break

```bash
#!/bin/bash

echo "Starting the loop"
for i in $(seq 1 10)
do
if [[ $i -eq 5 ]]
then
break
else
echo $i
fi
done
echo "Ending the loop"
```

```console
root@ahmadhassan:~/bash/lect16# ./break_st.sh
Starting the loop
1
2
3
4
Ending the loop
```
