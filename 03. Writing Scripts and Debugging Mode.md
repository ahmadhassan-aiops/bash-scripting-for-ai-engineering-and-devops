# 03. Writing Scripts and Debugging Mode

## Steps for Writing a Bash Script

1. Gather the information first.
2. Know the manual commands for the task.
3. Add the shebang line (`#!/bin/bash`).
4. Create a `.sh` file and write your commands in it.
5. Set the permission and run the script with `./<script name>` or `/<full path of script>`.

## Changing Your Shell

```bash
echo $SHELL
chsh
```

When prompted, provide the path of the shell you want to switch to, for example `/bin/bash`.

## Debugging Mode

| Command | Effect |
|---|---|
| `set -x` | Enable debugging |
| `set +x` | Disable debugging |

```bash
vim myfirst.sh
```

```bash
#!/bin/bash
pwd
date
echo hello
echo "bye"
set -x
echo "Today date is $(date)"
echo "Hi your current directory is : $(pwd)"
set +x
echo "======="
```

**Output of `./myfirst.sh`:**

```console
/root/bash

hello
bye

+ echo 'Today date is Sunday 12 June 2022 12:33:55 PM IST'
Today date is Sunday 12 June 2022 12:33:55 PM IST
++ pwd
+ echo 'Hi your current directory is : /root/bash'
Hi your current directory is : /root/bash
+ set +x
=======
```

## Task: Changing Directories in a Script

```bash
#!/bin/bash
echo "My current directory is : $(pwd)"
cd /home/ahmad/
echo "my changed directory is : $(pwd)"
cd /home/ahmad
```

**Task:** I want the directory change to apply to my current command line.

**Answer:** run the script with `source`, and the directory changes in your shell:

```bash
source second.sh
```
