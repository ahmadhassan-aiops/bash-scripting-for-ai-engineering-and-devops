# 08. Positional Parameters

## Variables Recap

```bash
echo "enter the number"
read ahmad
```

`ahmad` → stores the input (e.g. `Ahmad`), and `$ahmad` reads it back.

```bash
a=10
a      # the name
$a     # the value
```

## Special Parameters

| Parameter | Meaning |
|---|---|
| `$0` | Program or script name |
| `$1` … `$9` | Parameters passed |
| `$#` | Total number of parameters |
| `$*` | All parameters passed |
| `$@` | Same as `$*` |
| `$$` | PID of the current shell |

## Example

```bash
#!/bin/bash
echo "This is positional parameter example script" $0
echo "Hello, My name is : " $1
echo "Here is " $2
echo "this is " $3
echo "total count value is " $#
echo "Display the parameter which are passed" $*
echo "Fetch information" $@
echo "PID of current shell"
echo "Exit status of last executed command " $?
```

**Output:**

```console

This is positional parameter example script ./test.sh
Hello, My name is :  King
Here is  Queen
this is  Prince
total count value is  5
Display the parameter the passed King Queen Prince AHMAD cloudops
Fetch information King Queen Prince AHMAD cloudops
PID of current shell
Exit status of last executed command  0
```

## Managing a Service

**With `read`:**

```bash
#!/bin/bash
echo  "Enter the service name which you want to check"
read service_name
echo  "Enter the status"
read status
sudo systemctl $status $service_name
```

**With positional parameters:**

```bash
#!/bin/bash
service_name=$1
status=$2
sudo systemctl $status $service_name
#./service_status.sh docker status
```

**With a usage check:**

```bash

#echo  "Enter the service name which you want to check"
```
