## Checking the Exit Status

```bash
echo $?
```

`$?` shows whether the previous command ran successfully. `0` means success; any other value means it failed.

```console
root@ahmadhassan:~/bash# [ "abc" == "def" ]; echo $?
1
root@ahmadhassan:~/bash# [ "abc" == "abc" ]; echo $?
0
root@ahmadhassan:~/bash# [ "abc" == "ABC" ]; echo $?
1
root@ahmadhassan:~/bash# [ 265 -gt 10 ]; echo $?
0
root@ahmadhassan:~/bash# [ 25 -gt 10 ]; echo $?
0
root@ahmadhassan:~/bash# [ 25 -gt 25 ]; echo $?
1
root@ahmadhassan:~/bash# [ 25 -lt 25 ]; echo $?
1
root@ahmadhassan:~/bash# [ 25 -le 25 ]; echo $?
0
root@ahmadhassan:~/bash# [ 25 -le 10 ]; echo $?
1
```

## if Syntax

```bash
if (condition)
then
 statement
else
 statement
fi
```

## Example: Compare a Number

```bash
vi num.sh
```

```bash
#!/bin/bash
echo -n "Enter any number of your choice"
read NUM

if [[ $NUM -gt 5 ]]
then
echo "The number is greater than 5. "
else
echo "The number is less than 5. "
fi
```

## Example: Pass or Fail

```console
root@ahmadhassan:~/bash/lect5# cat pass.sh
```

```bash
#!/bin/bash
echo -n "Your score is = "
read score
if [[ $score -gt 80 ]]
then
echo "You have passed the exam"
else
echo "Sorry , You are fail"
fi
```

## Example: Largest of Three Numbers

```bash
vi largenumber.sh
```

```bash
#!/bin/bash
echo -n "a value: "
read a
echo -n "b value: "
read b
echo -n "c value :"
read c
if [[ $a -ge $b ]] && [[ $a -ge $c ]]
then
 echo "a is BIG because value is $a"
elif [[ $b -ge $a ]] && [[ $b -ge $c ]]
then
 echo "b is BIG"
else
 echo "c is BIG"
fi
```
