## Syntax

```bash
file name | cut <option>
# or
cut <option> filename
```

| Option | Meaning |
|---|---|
| `-b`, `--bytes=LIST` | Select only these bytes |
| `-c`, `--characters=LIST` | Select only these characters |
| `-d`, `--delimiter=DELIM` | Use DELIM instead of TAB as the field delimiter |
| `-f`, `--fields=LIST` | Select only these fields; also print lines without a delimiter unless `-s` is given |
| `-n` | (ignored) |
| `--complement` | Invert the selected bytes, characters or fields |

## Custom Delimiter

The `/etc/passwd` file uses `:` as its delimiter:

```
cloudops:x:1006:1008::/home/cloudops:/bin/bash
```

```console
# cat /etc/passwd | cut -d ":" -f 1
# cat /etc/passwd | cut -d ":" -f 1-4 | grep "cloudops"
cloudops:x:1006:1008
root@ahmadhassan:~/bash/lect22# cat /etc/passwd | cut -d ":" -f 1- | grep "cloudops"
cloudops:x:1006:1008::/home/cloudops:/bin/bash
```

## `--output-delimiter`

```console
# cat /etc/passwd | cut -d ":" -f 1-10 --output-delimiter="-->" | grep cloudops
cloudops-->x-->1006-->1008-->-->/home/cloudops-->/bin/bash
```

## `--complement`

A way to invert the selection:

```bash
cat /etc/passwd | cut --complement -d ":" -f 1
```

## Real-World Examples

```bash
docker -v | cut -d "," -f 1 | cut -d " " -f 3

free -gt | grep -E "Total:" | cut -d " " -f 13

df -h | grep -E "/dev/mapper/vgubuntu-root" | cut -d " " -f 10
```
