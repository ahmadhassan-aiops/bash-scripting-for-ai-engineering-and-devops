# 12. until Loop

## Syntax

```bash
until <condition>
do
statement
done
```

| Loop | Runs while the condition is |
|---|---|
| `until` | False, until it becomes true |
| `while` | True, until it becomes false |

## Example

```bash
vim simple.sh
```

```bash
#!/bin/bash
start=1
until [[ $start -ge 5 ]] # Keeps running while False, until True is reached (5 = 5)
do
echo "Num is : $start"
((start++))
done
```

```bash
#!/bin/bash

while [[ $start -le 10 ]]  # Keeps running while True, until False is reached (10 = 10)
do
echo "My Loop $start"
#((start++))
start=`expr $start + 1`   # this expression can be used instead of start++
done
```

## Waiting for a File

```console
root@ahmadhassan:~/bash/lect12# cat file_exist.sh
```

```bash
#!/bin/bash
until [[ -e /tmp/file ]]   # -e checks whether the file exists
do
echo "file does not not exist"
sleep 1
done
echo "File exist in the system"
```

## Difference

A `while` loop is designed to run while a condition is satisfied, and it terminates once that condition returns false. An `until` loop, on the other hand, runs while the condition returns false and terminates only when the condition returns true.
