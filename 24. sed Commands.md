# 24. sed Commands

`sed` is a filter and a **stream editor**.

## What sed Does

1. Display contents
2. Find
3. Replace
4. Modify

## Syntax

```bash
filename or command | sed [options]
sed [option] filename
```

## Displaying Lines

```bash
sed ' ' myuser.txt
# or
cat myuser.txt | sed ' '
```

| Command | Prints |
|---|---|
| `cat myuser.txt \| sed -n '4p'` | Line 4 |
| `cat myuser.txt \| sed -n '$p'` | The last line |
| `cat -n myuser.txt \| sed -n '1,5p'` | Lines 1 to 5 |
| `cat -n myuser.txt \| sed -n '5,$p'` | Line 5 to the last line |
| `cat -n myuser.txt \| sed -n '3,15p'` | Lines 3 to 15 |
| `cat -n myuser.txt \| sed -n '/aadmin/,$p'` | From `aadmin` to the last line |

The same range with awk:

```bash
cat -n myuser.txt | awk 'NR>=3 && NR <=15 {print $0}'
```

## Searching

```console
# cat -n myuser.txt | sed -n '/cloudops/p'
cloudops:x:1006:1008::/home/cloudops:/bin/bash
```

Use double quotes to search with a shell variable:

```console
# name=ahmad
root@ahmadhassan:~/bash/lect25# echo $name
ahmad
# cat myuser.txt | sed -n '/ahmad/p'
ahmad:x:1000:1000:Ahmad,,,:/home/ahmad:/bin/bash
root@ahmadhassan:~/bash/lect25# cat myuser.txt | sed -n '/$name/p'
root@ahmadhassan:~/bash/lect25# cat myuser.txt | sed -n "/$name/p"
ahmad:x:1000:1000:Ahmad,,,:/home/ahmad:/bin/bash
```

## Deleting Lines

```bash
sed -i '1,10d' myuser.txt

sed -i '/cloudops/d' myuser.txt

sed -i.bck '/cloudops/d' myuser.txt     # changes the file and creates a .bck backup

sed -i.bck '/cloudops/!d' myuser1.txt   # removes everything except cloudops
```

## Replacing Text

Syntax: `filename | sed 's/old/new/'`

```bash
cat myuser.txt | sed 's/cloudops/CloudOps/'

sed -i 's/cloudops/CloudOps/' myuser.txt

cat myuser.txt | sed 's/ahmad/AHMAD/g'

cat myuser.txt | sed 's/testuser/Ttestuser/2'   # replaces only the second match
```

## Inserting and Appending Lines

| Command | Meaning |
|---|---|
| `i` | Insert before the line |
| `a` | Append after the line |

```console
# sed -i '1i Sr.no,IP,Hostname' data.csv
root@ahmadhassan:~/bash/lect25# cat data.csv
```

## Patterns

```console
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/serve1/p'
1,192.168.1.2,serve1
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/serve[1,2]/p'
1,192.168.1.2,serve1
2,192.168.1.3,serve2
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/serve*/p'
1,192.168.1.2,serve1
2,192.168.1.3,serve2
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/serve?/p'
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/serve./p'
1,192.168.1.2,serve1
2,192.168.1.3,serve2
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/serve1$/p'
1,192.168.1.2,serve1
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/1/p'
1,192.168.1.2,serve1
2,192.168.1.3,serve2
root@ahmadhassan:~/bash/lect25# cat data.csv | sed -n '/^1/p'
1,192.168.1.2,serve1
```

**Delete comment lines from a file:**

```bash
sed -i '/^#/d' sshd_config
```

## Special Characters

| Pattern | Meaning |
|---|---|
| `\s` | Space |
| `/word/p` | Print lines containing `word` |
| `\:` | Escaped special character |

```console
# cat /var/log/auth.log | sed -n '/Jul\s16\s19\:09/p' > ahmad.txt
root@ahmadhassan:~/bash/lect25# cat ahmad.txt

Jul 16 19:09:01 ahmadhassan CRON[34790]: pam_unix(cron:session): session closed for user root
```
