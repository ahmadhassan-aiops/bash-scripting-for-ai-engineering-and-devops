# 06. Conditional Statements (Part 2)

## Method 1: Check with `which` and `$?`

```bash
#!/bin/bash

echo "Enter the service which you want check install or not: "
read service_name
command=$(which $service_name)
status=$(echo $?)
#echo $command
#echo $status
if [[ $status -eq 0 ]]
then
 echo "$service_name is installed on this machine"
 echo "The docker version is : $($service_name -v)"
else
 echo "THe $service_name is not installed"
fi
```

## Method 2: Check with `ps -ef | grep`

Count the matching processes:

```bash
#!/bin/bash
commands=$(ps -ef | grep docker | wc -l)
```

```bash
#!/bin/bash
commands=$(ps -ef | grep docker | wc -l)
echo $commands
if [[ $commands -ne 1 ]]
then
echo "Docker is installed"
else
echo "Docker is not installed"
fi
```

Ask the user for the service name:

```bash
#!/bin/bash
echo "Enter the service name which you want check installed or not"
read service_name
commands=$(ps -ef | grep $service_name | wc -l)
if [[ $commands -ne 1 ]]
then
 echo "$service_name is installed"
else
 echo "$service_name is not installed"
fi
```

## Summary

We learned two ways to check whether a service is installed:

1. With the `which` command and `echo $?`.
2. With `ps -ef | grep <service name>`.
