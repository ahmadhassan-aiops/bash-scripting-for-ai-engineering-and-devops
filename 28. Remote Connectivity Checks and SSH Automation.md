## Script: Check Connectivity with ping

```console
[root@client1 lec29]# cat serverIP.csv
Sr.no,ServerIp,servername
1,google.com,client1.example.com
2,github.com,app2
3,facebook.com,SFTP
```

```bash
#!/bin/bash
IP=$(cat serverIP.csv | awk 'NR>1' | cut -d ',' -f2)

for i in $IP
do
        ping -c 1 $i
        status=$(echo $?)
        echo $status
done
```

The raw `ping` output is hard to read, especially for a non-technical manager, so we simplify it.

## Redirection

| Operator | Redirects |
|---|---|
| `>` | Output to a file |
| `1>` | Standard output (same as `>`) |
| `2>` | Errors |
| `&>` | Both standard output and errors |

**/dev/null** is a special file (not a directory) used to discard unwanted output.

```console
[root@client1 lec29]# ping -c 1 google.com 1> /dev/null
[root@client1 lec29]#
```

## Script: Readable Connectivity Report

```bash
#!/bin/bash
IP=$(cat serverIP.csv | awk 'NR>1' | cut -d ',' -f2)

for i in $IP
do
        ping -c 1 $i 1> /dev/null
        status=$(echo $?)
        if [[ $status -eq 0 ]]
        then
                echo "$i is connected "
        else
                echo "$i is not connected"
        fi
done
```

```console
[root@client1 lec29]# ./IP_fetch.sh
google.com is connected
github.com is connected
facebook.com is connected
192.168.1.6 is not connected
```

> **Interview question:** how can you check connectivity to a server? With `ping`, as above.

**Bonus:** transfer files from one machine to another:

```bash
scp -vr <filename> <username>@<IP address>:<destination path>
```

## Running Commands on Remote Machines

You can log in with SSH in two ways: password-less or password-based.

### Password-Less Authentication

Make sure the `aadmin` user exists on both machines with a password. Then, as `aadmin`, generate an SSH key (press Enter at every prompt) and copy it to the other machine:

```bash
ssh-keygen
cd /home/aadmin/.ssh/
ssh-copy-id 192.168.23.131
```

```console
[aadmin@client1 .ssh]$ ssh-copy-id 192.168.23.131
/usr/bin/ssh-copy-id: INFO: Source of key(s) to be installed: "/home/aadmin/.ssh/id_rsa.pub"
/usr/bin/ssh-copy-id: INFO: attempting to log in with the new key(s), to filter out any that are already installed
/usr/bin/ssh-copy-id: INFO: 1 key(s) remain to be installed -- if you are prompted now it is to install the new keys
aadmin@192.168.23.131's password:

Number of key(s) added: 1
```

Now SSH logs in without asking for a password:

```console
[aadmin@client1 .ssh]$ ssh 192.168.23.131
Last login: Sat Jul  1 13:35:48 2023
```

You can do the same for the `root` user instead of `aadmin`.

**Run a command on the remote machine:**

1. `ssh-keygen`
2. `ssh-copy-id <IP or hostname of client machine>`
3. `ssh <IP or hostname of client machine> "<command you want to run>"`

```console
[aadmin@client1 bash]$ ssh client2 "hostname"
client2.example.com
```

### Password-Based Connection

Install `sshpass` on the server machine (the one running the script):

```bash
apt-get install sshpass
# or
yum install sshpass
```

Store the client machine's password in `pass.txt`, then run the command from the directory that contains it:

```bash
sshpass -f pass.txt ssh -n -o StrictHostKeyChecking=No -o PubkeyAuthentication=No client1 "ifconfig"
```

- `client1` can be written more specifically as `root@<IP or hostname>` or `aadmin@<IP or hostname>`.
- With just `client1`, SSH logs in as the user running the command (root here; run it as `aadmin` and it logs in as `aadmin`).
- `-v` adds verbose output.

```console
[aadmin@client1 bash]$ sshpass -v -f pass.txt ssh -n -o StrictHostKeyChecking=No -o PubkeyAuthentication=No client1 "ps"
SSHPASS searching for password prompt using match "assword"
SSHPASS read: aadmin@client1's password:
SSHPASS detected prompt. Sending password.
SSHPASS read:

    PID TTY          TIME CMD
  38023 ?        00:00:00 sshd
  38026 ?        00:00:00 ps
```

Run several commands at once, separated by semicolons:

```bash
sshpass -f pass.txt ssh -n -o StrictHostKeyChecking=No -o PubkeyAuthentication=No aadmin@192.168.1.8 "hostname;ifconfig;date"
```

**Where do remote commands run?** In the home directory of the user you logged in as:

```console
[root@client1 bash]# sshpass -f pass.txt ssh -n -o StrictHostKeyChecking=No -o PubkeyAuthentication=No client1 "pwd"
/root
[root@client1 bash]# su aadmin
[aadmin@client1 bash]$ sshpass -f pass.txt ssh -n -o StrictHostKeyChecking=No -o PubkeyAuthentication=No client1 "pwd"
/home/aadmin
```

## Task: Ask the User for the Command and Show a Count

You can also add your own machine to `serverIP.csv` (run `ssh-copy-id <IP or hostname>` first for password-less access).

```console
[root@client1 lec29]# cat serverIP.csv
Sr.no,ServerIp,servername
1,client2,client2
2,192.168.148.171,ahmadhassan
```

```bash
#!/bin/bash
IP=$(cat serverIP.csv | awk 'NR>1' | cut -d ',' -f2)

count=0
for i in $IP
do
        ping -c 1 $i 1> /dev/null
        status=$(echo $?)
        if [[ $status -eq 0 ]]
        then
                read -p "Enter the command you want to run : " command
                echo "$i is connected "
                ssh $i "$command"
                count=$((count + 1))
                echo $count
        else
                echo "$i is not connected"
        fi
done
```

```console
[root@client1 lec29]# ./IP_fetch.sh
Enter the command you want to run : pwd
client2 is connected
/root
1
Enter the command you want to run : hostname
192.168.148.171 is connected
ahmadhassan
2
```

## Script: Connected and Failed Totals

```bash
#!/bin/bash
IP=$(cat serverIP.csv | awk 'NR>1' | cut -d ',' -f2)

fail_count=0
con_count=0
for i in $IP
do
        ping -c 1 $i 1> /dev/null
        status=$(echo $?)
        if [[ $status -eq 0 ]]
        then
                echo "$i is connected "
                sshpass -f /bash/pass.txt ssh -n -o StrictHostKeyChecking=No -o PubkeyAuthentication=No $i "uname" 1> /dev/null
                con_count=$(( con_count + 1 ))
                echo $con_count
        else
                echo "$i is not connected"
                fail_count=$(( fail_count + 1 ))
                echo $fail_count
        fi
done

echo "Total $con_count is connected"
echo "Total $fail_count is not connected"
```
