# 23. awk Scripting

awk can be used in two ways:

1. As an awk command
2. As the awk scripting language

## Syntax

```bash
filename | awk 'BEGIN {start_action} condition {action} END {stop_action}'
filename | awk -f <filename.awk>
```

**OFS** = Output Field Separator

```console
# date | awk '{print $2,$3,$4}'
16 July 2022
root@ahmadhassan:~/bash/lect24# date | awk 'OFS="-" {print $2,$3,$4}'
16-July-2022
root@ahmadhassan:~/bash/lect24# date | awk 'OFS="/" {print $2,$3,$4}'
16/July/2022
```

## BEGIN Block

```bash
awk 'BEGIN {print "Hey, I am Ahmad Hassan"}'
```

**From an awk file:**

```console
# cat simple.awk
BEGIN {
print " Hey , I am Ahmad Hassan"
}
root@ahmadhassan:~/bash/lect24# awk -f simple.awk
Hey , I am Ahmad Hassan
```

**As an executable awk script:**

```console
# which awk
/usr/bin/awk

# cat simple.awk
#!/usr/bin/awk -f
BEGIN {
print " Hey , I am Ahmad Hassan"
}
root@ahmadhassan:~/bash/lect24# ./simple.awk
Hey , I am Ahmad Hassan
```

## Practical Examples

```console
# who | awk 'BEGIN {print "Active Session"} {print $1,$4}'
Active Session
ahmad 15:29
aadmin 15:35
```

```bash
cat /etc/passwd | awk -F ":" '{print $1,$3,$6}'

cat /etc/passwd | awk -F ":" '$3 >=1000 {print $1,$3,$6}'

cat /etc/passwd | awk -F ":" '$3 >=1000 {print $1,$3,$6}' | wc -l

cat /etc/passwd | awk -F ":" '$3 >=1000 {print $1,$3,$6}' > mycurrentuser.txt
```

## Variables in awk

```console
# awk 'BEGIN { }'
# awk 'BEGIN {ali=100 }'

root@ahmadhassan:~/bash/lect24# awk 'BEGIN {ali=100 print $ali }'
awk: cmd. line:1: BEGIN {ali=100 print $ali }
awk: cmd. line:1:                ^ syntax error

root@ahmadhassan:~/bash/lect24# awk 'BEGIN {ali=100 print ali }'
awk: cmd. line:1: BEGIN {ali=100 print ali }
awk: cmd. line:1:                ^ syntax error

root@ahmadhassan:~/bash/lect24# awk 'BEGIN {ali=100; print ali }'
100

root@ahmadhassan:~/bash/lect24# awk 'BEGIN {ali=100; print $ali }'

root@ahmadhassan:~/bash/lect24# awk 'BEGIN {ali=100; print ali }'
100
```

## Options Recap

| Option | Meaning |
|---|---|
| `-v` | Variable |
| `-f` | File |
| `-F` | Field separator |

```console
# num=51
root@ahmadhassan:~/bash/lect24# awk -v n=100 'BEGIN { print n}'
100
root@ahmadhassan:~/bash/lect24# awk -v n=101 'BEGIN { print n}'
101
root@ahmadhassan:~/bash/lect24# awk -v n=num 'BEGIN { print n}'
num
root@ahmadhassan:~/bash/lect24# awk -v n=$num 'BEGIN { print n}'
51
```

## Custom Field Separators

```console
# echo "Ahmad Hassan Ali"
Ahmad Hassan Ali
root@ahmadhassan:~/bash/lect24# echo "Ahmad Hassan Ali" | awk -F " " '{print $1}'
Ahmad
root@ahmadhassan:~/bash/lect24# echo "Ahmad Hassan Ali" | awk -F " " '{print $2}'
Hassan
root@ahmadhassan:~/bash/lect24# echo "Ahmad Hassan Ali" | awk -F " " '{print $3}'
Ali
root@ahmadhassan:~/bash/lect24# echo "Ahmad Hassan Ali" | awk -F Hassan '{print $3}'

root@ahmadhassan:~/bash/lect24# echo "Ahmad Hassan Ali" | awk -F Hassan '{print $1}'
Ahmad
root@ahmadhassan:~/bash/lect24# echo "Ahmad Hassan Ali" | awk -F Hassan '{print $2}'
Ali
```

## if Conditions

```console
# cat num.txt
20
1
21
16
5
21
50
70
21
89

# cat num.txt | awk '{if ($1 >=30 ) print $1}'
50
70
89

# cat num.txt | awk '{if ($1 <=30 ) print $1}'
20
1
21
16
5
21
21

# cat num.txt | awk '{if ($1 >=10 && $1 <=30 ) print $1}'
20
21
16
21
21
```

> **Note:** use `$1` (not `$i`) to refer to the first field. In this `num.txt` file each line has a single field, so the output is the same either way.

## Loops

```bash
awk 'BEGIN {for (i=1; i<=10; i++) print "The number", i}'
```

## Formatted Reports

```bash
ls -ltrh | awk '{print $9,$5}'

ls -ltrh | awk -v OFS='\t\t' 'BEGIN {printf "%s\t\t%s\n", "Name", "Size"}{print $9,$5} '
```
