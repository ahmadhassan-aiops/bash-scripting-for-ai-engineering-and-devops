# 14. echo Flags, Here Documents and Comments

> **Note:** the `-e` option enables interpretation of backslash escapes.

## Escape Sequences

**`\` Backslash**

```console
root@ahmadhassan:~# echo -e "My name is \"Ahmad Hassan\", I am from Rawalpindi, Pakistan"
My name is "Ahmad Hassan", I am from Rawalpindi, Pakistan
```

**`\a` Alert (BEL)**

```console
root@ahmadhassan:~# echo -e "\aMy sample shell script "
My sample shell script
```

**`\b` Backspace**

```console
root@ahmadhassan:~# echo -e "Ahm\bad Hassan"
Ahad Hassan

root@ahmadhassan:~# echo -e "Ahmad \bHassan"
AhmadHassan
```

**`\c` Suppress trailing output**

```console
root@ahmadhassan:~# echo -e "Ahmad Hassan , \nI am from\c Rawalpindi"
Ahmad Hassan ,
I am from
```

**`\f` Form feed** (in short, clears the screen)

```console
root@ahmadhassan:~# echo -e "\fAhmad Hassan , \nI am from Rawalpindi"
Ahmad Hassan ,
I am from Rawalpindi
```

**`\n` New line**

```console
# echo -e "Ahmad Hassan , \nI am from Rawalpindi"
Ahmad Hassan ,
I am from Rawalpindi
```

**`\t` Horizontal tab**

```console
root@ahmadhassan:~# echo -e "Ahmad Hassan from rawalpindi"
Ahmad Hassan from rawalpindi
root@ahmadhassan:~# echo -e "Ahmad Hassan from \trawalpindi"
Ahmad Hassan from       rawalpindi
root@ahmadhassan:~# echo -e "Ahmad Hassan from \t\trawalpindi"
Ahmad Hassan from               rawalpindi
root@ahmadhassan:~# echo -e "Ahmad Hassan from \t\t\trawalpindi"
Ahmad Hassan from                       rawalpindi
```

**`\v` Vertical tab**

```console
root@ahmadhassan:~# echo -e "Ahmad Hassan from \vRawalpindi"
Ahmad Hassan from
Rawalpindi
root@ahmadhassan:~# echo -e "Ahmad Hassan from \v\tRawalpindi"
Ahmad Hassan from
Rawalpindi
```

## Environment Variables in a Script

```console
root@ahmadhassan:~/bash/lect14# cat HS.sh
```

```bash
#!/bin/bash
echo "My current user is $USER"
echo "My current working direction is $PWD"
```

```bash
#!/bin/bash
echo "
My current user is $USER"
echo "My current working directory is $PWD
"
```

```console
root@ahmadhassan:~/bash/lect14# ./HS.sh
My current user is root
My current working directory is /root/bash/lect14
```

## Here Documents

```bash
#!/bin/bash
cat << EOF
My current user is $USER
My current working directory is $PWD
EOF
```

```console
root@ahmadhassan:~/bash/lect14# ./HS.sh
My current user is root
My current working directory is /root/bash/lect14
```

**Append the output to a file:**

```console
root@ahmadhassan:~/bash/lect14# ./HS.sh >> file1.txt
root@ahmadhassan:~/bash/lect14# cat file1.txt
My current user is root
My current working directory is /root/bash/lect14
```

**Write to a file from inside the script:**

```bash
#!/bin/bash
cat << EOF > file2.txt
My current user is $USER
My current working directory is $PWD
EOF
```

```console
root@ahmadhassan:~/bash/lect14# ./HS.sh
root@ahmadhassan:~/bash/lect14# cat file2.txt
My current user is root
My current working directory is /root/bash/lect14
```

## Here Strings and tr

```console
root@ahmadhassan:~/bash/lect14# echo "We are learning bash at CloudOps Academy" | tr [a-z] [A-Z]
WE ARE LEARNING BASH AT CLOUDOPS ACADEMY

root@ahmadhassan:~/bash/lect14# tr [a-z] [A-Z] <<< "we are learning bash at cloudops academy"
WE ARE LEARNING BASH AT CLOUDOPS ACADEMY
```

```console
# ahmad="we are learning bash at cloudops academy"
root@ahmadhassan:~/bash/lect14# echo $ahmad
we are learning bash at cloudops academy
root@ahmadhassan:~/bash/lect14# tr [a-z] [A-Z] <<< $ahmad
WE ARE LEARNING BASH AT CLOUDOPS ACADEMY
```

```console
# docker -v | tr [a-z] [A-Z]
DOCKER VERSION 20.10.14, BUILD A224086
root@ahmadhassan:~/bash/lect14# docker -v
Docker version 20.10.14, build a224086
```

## Comments

**Single-line comments:**

```bash
#Name: Ahmad Hassan
#Script name: comments.sh
#Script purpose : for education
echo "Hi"
```

**Multi-line comments:**

```bash
<< EOF
Name: Ahmad Hassan
Script name: comments.sh
Script purpose : for education
EOF
echo "Hi"
```

or

```bash
: "
Name: Ahmad Hassan
Script name: comments.sh
Script purpose : for education
"
```

or

```bash
: '
Name: Ahmad Hassan
Script name: comments.sh
Script purpose : for education
'
echo "Hi"
```
