# 26. Scheduling Tasks with cron and Email Alerts

## Email Setup on an Ubuntu Machine

1. Log in to your Gmail account.

2. Open **Manage your Google Account**:
   https://myaccount.google.com/

3. Go to **Security** and turn on **2-Step Verification**.

4. Go to **Security → App passwords** and create an app password.
   ```
   App password: <your-gmail-app-password>
   ```

5. On your Ubuntu/Linux machine, install sendmail:

   **Ubuntu:**
   ```bash
   apt-get update
   apt-get install sendmail mailutils
   ```

   **RHEL 9:**
   ```bash
   sudo dnf update -y
   sudo dnf install sendmail sendmail-cf mailx -y
   ```

6. Create the `authinfo` directory:
   ```bash
   cd /etc/mail
   mkdir authinfo
   chmod 700 authinfo/
   cd authinfo/
   ```

   ```console
   # cat gmail
   AuthInfo: "U:root" "I:<your-email>@gmail.com" "P:password"
   ```

   ```bash
   makemap hash gmail < gmail
   ```

7. Edit `sendmail.mc` and add the following after line 101:

   ```
   #GMail settings:
   define(`SMART_HOST',`[smtp.gmail.com]')dnl
   define(`RELAY_MAILER_ARGS', `TCP $h 587')dnl
   define(`ESMTP_MAILER_ARGS', `TCP $h 587')dnl
   define(`confAUTH_OPTIONS', `A p')dnl
   TRUST_AUTH_MECH(`EXTERNAL DIGEST-MD5 CRAM-MD5 LOGIN PLAIN')dnl
   define(`confAUTH_MECHANISMS', `EXTERNAL GSSAPI DIGEST-MD5 CRAM-MD5 LOGIN PLAIN')dnl
   FEATURE(`authinfo',`hash -o /etc/mail/authinfo/gmail.db')dnl
   ```

8. Rebuild the configuration and reload sendmail:
   ```bash
   make
   /etc/init.d/sendmail reload
   ```

## crontab Syntax

```
MIN HOUR DOM MON DOW CMD
```

| Field | Description | Allowed values |
|---|---|---|
| MIN | Minute | 0 to 59 |
| HOUR | Hour | 0 to 23 |
| DOM | Day of month | 1 to 31 |
| MON | Month | 1 to 12 |
| DOW | Day of week | 0 to 6 |
| CMD | Command | Any command to be executed |

Helper: https://crontab.guru/

```bash
crontab -e
```

```
* * * * * echo $(date) >> /tmp/ahmad.txt
```

## Low-Memory Alert Script

```bash
free -gt | awk 'NR==4' | awk '{print $4}'
```

```console
# cat memory.sh
```

```bash
#!/bin/bash
free_mem=$( free -gt | awk 'NR==4' | awk '{print $4}')

if [[ $free_mem -le 2 ]]
then
echo -e "Server memory very low with $free_mem" | mail -s "ALERT | MEMORY LOW " <your-email>@gmail.com
echo "Mail has been sent due to low memory $free_mem"
fi
```
