## 🚀 How to use it

1. Open a terminal on any Linux machine (Ubuntu or RHEL) or a VM.
2. Follow the topics in order. Create each script with `vim <name>.sh`, give it execute permission with `chmod +x <name>.sh`, then run it with `./<name>.sh`.
3. Try the tasks at the end of a topic before checking the solution in the next one, then test yourself with topic 29.

> Topics 26 and 28 need extra setup: a Gmail app password for email alerts, and two Linux machines for the SSH automation scripts.
