# 25. find Command

## Syntax

```bash
find <path> <action> <file or patterns>
```

## By Name and Type

```bash
find /root/bash/lect26/files -name ahmad1.txt

find . -name ahmad1.txt

find . -type d -name ahmad      # find directories

find . -type f -name ahmad      # find files

find . -type f -name *.csv
```

## By Owner and Group

```bash
find . -user root

find . -group root
```

## By Permission

```bash
find . -type f -perm 0755 -print

find . -perm /u=r
find . -perm /u=x
find . -perm /u=w
```

## Running an Action on Results

```bash
find /root/bash/lect26/files/dir1 -type f -name "*.txt" -exec rm -f {} \;

find . -type d -perm 777 -print -exec chmod 755 {} \;
```

## By Size

```bash
find . -size 50M
find . -type f -size 0
find . -type f -size 0 | wc -l
find . -type f -name ".*"
```

## By Time

| Option | Meaning |
|---|---|
| `-mtime +n` | Modified more than n days ago |
| `-mtime -n` | Modified less than n days ago |

```bash
find . -type d -mtime -10    # days
find . -cmin -60             # last 60 minutes
find . -mmin -120

find . -newermt "yesterday"
ls -ltrh | grep 'Jul 16'
```
